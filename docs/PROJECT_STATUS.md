> 状态日期：2026-07-29  
> 事实源：当前本地工作树  
> 产品阶段：可运行、可测试的工程因果纵切，不是完整飞船引擎  
> 产品名：**远穹**（「远航」为旧称/主题别名）
>
> 本页概括当前体验与已落地边界。2026-07-24 / 07-26 阶段性关机备忘已迁入[历史接手归档](./archive/handoff/README.md)；与归档冲突时以代码与本页为准。

## 当前体验

任务从舰桥授权台开始。玩家签发起点、终点和最高指令后进入五个主视图：舰桥、舰务、乘员、AI 观察、人工干预。舰桥首屏以全宽前向主视窗（WebGL 天球）、任务相位、剩余航程、跃迁进度和右舷居住环转速台组成；转速台只保留由观测 `relativeRpm` 驱动的 A/B 对转双环，转向取自观测值符号。右侧为可筛选的舰桥日志，窄屏时收为抽屉。舰务视图分四格：左上是占主视觉位的 WebGL 舰体剖视（可悬停/点选区带），右上是 14 行实时负载（转速轴承、送风分环流量、累计未送达等以次级行随读数给出），左下是每环 12 列两行的 48 区选择器，右下是区带检查器（含 `ZoneRole` 中文标签）。原先那张示意性节点拓扑图已移除——它的 6 格里有 5 格只是右侧负载条的重复读数，连接线不对应任何真实拓扑，且第 5 个节点从未有过定位样式。任务未启动时离线卡显示诚实空态，不虚构 MW/g 读数。

时间由 Worker 内 `SimulationTimeDirector` 权威推进。当前有七档倍率：`1×`、`1m/s`、`30m/s`、`1h/s`、`2h/s`、`6h/s`、`1D/s`，对应快捷键 `1`–`7`；`Space` 暂停或继续。界面时钟在 Worker 状态之间按有效倍率线性插值，不再每 `250 ms` 跳一次。Worker 会把步进精确切到舰长的下一个决策截止点，并在发布状态前原子取得 `llm-waiting` 暂停令牌；同刻告警由这一轮决策一并处理并推进下一截止点，部门咨询、舰长研判和命令完成后才从该时刻继续。舰长 LLM 调用失败时不推进例行截止点，解冻后可按原截止点重试。

## 已落地边界

- 独立 Web Worker 持有物理世界真值，React 只发送结构化命令并消费投影。
- `lib/sim/worker.ts` 已收缩为编排层（消息协议、时间导演、耦合步进、快照事务、命令总线准入）。遥测投影下沉到 `lib/sim/projection.ts`，环境剂量与宜居阈值下沉到 `lib/sim/habitability.ts`，上帝干预的解析与副作用下沉到 `lib/sim/interventions.ts`，`36` 种舰令改为 `lib/sim/command-handlers/` 按域分文件的注册表并由 mapped type 做编译期穷尽检查。四者均为无状态纯函数集合，域单例由 worker 显式传入或经 getter 读取，保证 restore 后不会作用于旧对象。
- 舰长世界工具的 schema 与解析统一在 `lib/llm/captain-world-tools.ts`（`CAPTAIN_WORLD_TOOLS` 共 `35` 项），此前基础工具内联在 `mission-control.tsx` 决策 effect 里、扩展工具在顶层，属于双份维护，已合并为单一真相源。
- 固定 `2,000` 名乘客与 `120` 名船员，含持久身份、休眠、生存剂量、口粮、记忆和体验纵切。
- 人员环境剂量/伤亡目标区统一走 `locationOverride`（有覆盖用覆盖，否则舱位映射区），不再只按固定舱位算暴露。
- 48 压力区物理节点不变；每区另有 `ZoneRole` 目录元数据（居住/公共/医疗/膳食/农业/货舱/工业/换乘，含中文标签）。舱位→区带按布局角色映射，不是哈希。
- 48 舱大气、双回路冷却、双母线电力、六自由度导航、双反向旋转环、A/B 水回收（额定约 `900 kg/day`/环）和有限维修网络参与同一确定性事务；基线净水约 `1.8e6 kg`、干粮约 `500_000 kg`，缺粮饥饿折损约 `0.0005 /s`。
- 医疗区（`ZoneRole: medical`）对清醒人员环境剂量/应激施加 `0.6×` 缓冲，表示急救监护能力，不是治疗魔法。
- 运营治疗任务完成时按患者所在区带缩放疗效：医疗区 `1.0×`，其他区带 `0.4×`（仍非完整生理/病床仿真）。
- 基线储备冰约 `3e6 kg`（`1.5e6 kg`/环），相对净水 `1.8e6 kg` 保留张力，不再是旧的 `8e6 kg` 松弛余量。
- 固定 `8` 个部门 actor 与 `32` 个关键乘客槽位构成 `40` 节点舰内 LLM 拓扑；玩家侧上帝助手在拓扑外独立配置。
- 舰长有跨周期记忆：每个决策周期必须调用 `record_captain_log` 写一条主观航行志（`voice` / `judgment` / `watching` / `concern` / `unresolved`），下一周期作为 `<memory>` 回注并明示「主观、可能含误判、不得当作观测事实」。环形保留 `24` 条，注入最近 `6` 条。该工具不计入每周期 `8` 条世界命令配额；舰长在近 `40` 个工具里漏写时，本轮会追发一次只挂载 `record_captain_log` 的补写请求，由舰长本人补记而不是由系统代笔，补写仍失败才记「航行志未更新」。
- 舰长可用 `set_watch_condition` 自设最多 `6` 条观察哨，只能监视 `WATCH_METRICS` 目录里的 `12` 个授权观测量（触发一次后自动失效）。原有 `8` 条硬阈值降级为安全网，优先级高于自设哨位；哨位被硬告警抢占时不丢失，仍以「已触发待复核」出现在 `<watch>`。
- Prompt 输出契约已拆成「反编造」与「结论频道」两层：反幻觉约束（禁止散文假装执行、禁止编造读数门槛、禁止遥测复读与伪表格）全部保留并进入全部舰载 Prompt；旧的「自由文本必须极短」「不要煽情演讲」「严禁输出舰长日志」等抑制人格的条款已移除，人格与权衡改由航行志 `voice` 承载。
- 部门有持久立场与正式异议：咨询调用现在携带 `file_dissent`（`note` / `formal` / `grave`），异议进入永久记录并可标记 `overridden` / `vindicated`；`<standing>` 回注本部门历史立场，`<dissent_ledger>` 让舰长看到未撤销的反对。异议是记录不是否决，舰长仍是最终拍板者。
- 多轮部门会议从第 `2` 轮起注入 `<peer_positions>`（上一轮同僚**指名**发言），部门可点名赞同或反驳。
- 关键乘客进入社会：`<around_you>` 提供关系圈（家人/同伴的粗分档状况）、所在区带群体情绪与听到的传言，全部为模糊口语分档，不含精确数值与单位。乘客可用 `file_passenger_grievance` 经命令总线向世界申诉队列立案（同人同类目已开立时幂等合并，队列上限 `256`），也可用 `share_passenger_rumor` 在本区带散播传言（上限 `48` 条，`72 h` 衰减）。
- Worker 每 tick 新增两项投影支撑上述认知：`zoneMood`（各有清醒人区带的加权情绪）与 `passengerCircles`（关键乘客关系圈，每人 ≤ `6` 人）。二者是投影不是持久状态，不参与快照版本。
- 关键乘客轮询仍是异步只读任务：提交申诉不申请暂停令牌、不冻结世界。
- 界面已暴露上述叙事：AI 观察视图含航行志流、部门异议与立场统计、观察哨分组；乘员视图含「流传中」传言板并强制标注「未经证实」。
- 舰长周期是唯一自动冻结世界的 LLM 周期；相关部门只在同一次冻结决策中按需咨询。授权观察是混合通道（`sensorView` / `controllerCommandState` / `operationsLedger`），分节标明延迟或指令态，不是上帝真值；投影核心在 `lib/sim/captain-observation.ts`。
- LLM 网关默认 `maxAttempts: 6`；舰长例行调用失败不消费/推进下一截止点。
- 关键乘客以单并发后台任务异步轮询，只能更新本人私有记录；调用等待期间世界继续按所选倍率运行。
- 活动破口使用守恒的加速泄压近似；气体外泄本身不会把玩家选择的时间倍率自动压低。
- 壳体威胁联锁与级联已落地（`lib/sim/hull-consequence.ts`、`lib/sim/jump-interlock.ts`）：活动破口禁跃迁、按环推力降额；未修破口约 30 min AHU / 2 h 冷却泵 / 6 h 轴承+休眠馈线级联；封口后设备故障仍须检修（非结构 FEM）。授权观测已接入壳体联锁投影：`sensorView.hullThreat` / 同公式 `jumpThermalProjection` / 带破口的 `pressureZoneAlerts`；破口时 `hull-threat` 优先于 `jump-ready`，热投影不过则 `jump-thermal-block`；UI 前置拦截 `execute_jump` 的 `jumpBlocked`/热联锁。`jump-ready` 告警 id 含跃迁完成次数，读档/新任务会清空告警生命周期。
- 舰长和玩家动作都通过权限、命令总线、执行器、物理求解和传感器链路；上帝原力覆写单独审计。上帝因果对未知/无法映射的 `eventType` 默认拒收；助手计划按步串行执行，支路故障枚举显式区分 A/B（裸 `*-spur-fault` = A 环卡死关闭）。
- 舰长运营任务按部门值班、对应馈线和设备状态累计工时；周期回报保留精确世界时刻，完成边界会参与 Worker 切片。
- A/B 制氧机按目标产率、生命保障供电和净水余量连续生产；氧气只入账 `atmosphereReserveKg`，耗水与氢副产物分别入账。舱区氧分压不会因制氧自动上升，须 `set-atmosphere-supply` 从储备转入指定压力区。
- `thermalAuthority: external-network` 时，`executeJump` 跳过聚合冷却剂升温（废热走冷却热母线），避免双热模型互相覆盖。
- 程序化 `sensor-drift` 会降级真实舱区大气传感器；`equipment-wear` 文案与物理注入仅绑定冷却泵；`power-fluctuation` / `hibernation-complication` 已接入电气因果；仅 `passenger-social` 保持叙事并带诚实前缀；农业叙事不再宣称“无产量”。
- 恒星耀斑对舰外辐照的增量约为 `+160 W/m²`（不再使用离谱的旧辐照量级）。
- 备件替代进入真实维修配方；替代件完成后留下持久设备降额，后续泵、空气处理机和水处理机控制受该上限约束。
- 人员转移先求解可通行舱室路径，门关闭、密封、受限或卡死会阻塞；安保调查占用小队与工时并留下案件结论。
- 主动扫描报告取完成时刻的延迟/噪声传感摘要（标明高权限通道，非上帝真值清单）；部署后的探测器/无人机使用有限电池，停放时受舰载支持供电充电。
- 农作产量按生命保障供电与农业舱带 CO₂ 分压因子缩放；生长耗水按尝试计量（缺电/缺 CO₂ 时浪费），另加设施灌溉开销（满强度约 `300 kg/day`/bay，随 intensity×供电，与区带人数配额无关）。
- 区带用水配额按 `ZoneRole` 默认（居住 3 / 膳食 6 / 农业 8 等 kg·人⁻¹·日⁻¹）；降阶需求模型，不是管网。
- A/B 每环一条可故障配水支路（`water-spur-a/b`）：`effectiveDeliveryFraction = commandedOpenFraction × conditionMultiplier`（nominal 1 / degraded 0.5 / stuck-closed 0）；船员日用与运营灌溉/生长取水按分数实扣，短欠记入 `undeliveredPotableKg` 与 `deliveryShortfallKgByRing`（质量诚实优先，不做口渴仿真）。舰长/生保可通过 `configure-water-distribution-spur` 设开度并将 degraded/stuck-closed 修回 nominal；不能注入卡死故障（仍属上帝 `water-spur-fault`）。
- A/B 每环一条可故障居住热送达支路（`cooling-spur-a/b`，挂在冷却回路上）：同式有效送达分数缩放该环舱热泵冷却；短欠记入 `undeliveredHabitatCoolingJ`（能量诚实优先，非全冷却剂管网）。舰长/工程可通过 `configure-habitat-thermal-delivery-spur` 设开度或修回 nominal；故障注入属上帝 `cooling-spur-fault`。
- 舰长世界命令队列对参数/权限/修订/资源争用等软拒绝记回执后继续，仅硬失败才暂停并跳过后续命令。
- 破口/低压/环异常告警可「定位」到舰务区检查器，或高亮实时负载里对应的居住环行。
- 舰长不会被系统预先强制咨询固定部门；只有舰长调用 `consult_departments` 后，所选部门才进入 1–3 轮冻结会议。
- 部门仍**没有**世界改写工具；`file_dissent` 只写记录，不进物理链路。
- 手动本地存档包含权威运行时、时间导演、程序化世界、生存账本、关键乘客轮询和全部人员状态。
- 手动存档介质为 IndexedDB（库 `farhorizon`、单槽 `manual`，实现于 `lib/persist/local-save-idb.ts`）；启动时一次性把旧 `localStorage` 键 `farhorizon-save` 迁入；写入失败时可回退 `localStorage`，并尽力清空 IDB 槽以免读到陈旧 IDB 副本。
- 日心星表 `lib/astro/star-catalog`：航路用三维欧氏距离（非 `|dSol_a−dSol_b|`）；单段跃迁上限 `5 ly`，`estimateMinLegs` 与签发 UI 一致。
- 舰长完备手册：`docs/CAPTAIN_HANDBOOK.md`；规范 Prompt 含 `<handbook>`（观测识字、跃迁/SOC、壳体破口联锁与级联、支路、O₂ 储备诚实、咨询政策、反编造门槛）。

更完整的能力与限制见[项目首页](../README.md)和[引擎架构](./ENGINE_ARCHITECTURE.md)。

## 仍未完成

- 真实星表、星历、轨道机动、多段航线与安全港。
- 全舰结构、烟火污染、连续生理、完整医疗、逐人拥挤/搬运和长期社会自治。
- 传言目前只进入乘客认知与界面，不改写物理、不影响群体士气数值，也不会自发在区带之间扩散（只按听者所在区带择优投喂）。
- 部门之间仍无自发消息总线；同僚发言只在舰长发起的会议轮次内可见。
- 异议的 `overridden` / `vindicated` 需由上层显式标记，尚无自动判定「后来事实证明部门是对的」的机制。
- 2088 名普通乘客仍无自主行为与日程；只有 `32` 名关键乘客有 LLM 声音。
- 通用设备级管网（水侧已有每环配水支路、冷却侧已有每环居住热送达支路最小纵切）、身份门禁允许名单、制造故障率和维修机器人逐舱路径。
- 自动/轮换存档、checksum、更完整旧格式迁移链与外部 LLM 响应重放（手动单槽 IndexedDB 已落地）。
- 系统化视觉回归、长航程守恒漂移和更完整的端到端事故场景。
- 外部通信的真实带宽、距离延迟、对端回复和外交状态。
