## 冲突处理

出现描述冲突时，按下面顺序判断：

1. 代码、类型和自动化测试决定“现在实际怎么运行”。
2. [当前状态](./PROJECT_STATUS.md)概括当前已经落地的能力和格式版本。
3. [产品规格](./PRODUCT_SPEC.md)决定产品要做成什么，以及哪些要求不可妥协。
4. [引擎架构](./ENGINE_ARCHITECTURE.md)决定如何逐步实现目标。
5. 线上页面、历史截图和旧存档都不能作为覆盖本地项目的依据。

修改功能时，应同时更新受影响的状态、规格或架构文档，并运行 `npm run check:docs`。
